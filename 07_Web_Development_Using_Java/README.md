# Web Development Using Java

This folder contains exercises, labs, and coursework from the university course **"Web Development Using Java"**.  
The course covers foundational frontend technologies and full-stack web application development with Java, Servlets, JSP, JDBC, and MySQL.

## 📘 Course Description
The course introduces both frontend design and backend web application development using Java technologies.  
Topics include:
- Frontend fundamentals: HTML5, CSS3 (responsive layouts, typography), and JavaScript (DOM manipulation, events, UI effects).
- Introduction to Java Web and Apache Maven project structure.
- JavaServer Pages (JSP) and Java Servlets.
- MVC (Model-View-Controller) architecture and DAO pattern.
- Database connectivity and CRUD operations using JDBC and MySQL.
- Web application deployment on Apache Tomcat.

## 🛠️ Tools & Languages
- **Java** (JDK 17 / 21)
- **HTML5, CSS3, JavaScript**
- **JSP & Java Servlets**
- **MySQL & JDBC**
- **Apache Maven & Apache Tomcat**

## 🎯 Learning Outcomes
By completing this course, I gained:
- The ability to build responsive web interfaces using HTML, CSS, and vanilla JavaScript.
- Proficiency in developing dynamic, data-driven web applications using Java Servlets and JSP.
- Practical experience applying MVC and DAO design patterns.
- Skills in integrating relational databases with Java via JDBC for full CRUD functionality.
- Hands-on experience with project build tools (Maven) and servlet containers (Tomcat).
